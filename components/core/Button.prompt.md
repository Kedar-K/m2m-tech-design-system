Primary action control; use the yellow `primary` variant for the one most important action on a view, `secondary` (ink) or `outline` for the rest.

```jsx
<Button variant="primary" size="lg">Book a strategy session</Button>
<Button variant="outline" leadingIcon={<PlayIcon/>}>Watch demo</Button>
```

Variants: primary, secondary, outline, ghost, danger. Sizes: sm/md/lg. `block` for full width; `as="a"` for links.
