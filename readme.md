# M2M Tech Design System

Design system exported from Claude Design, plus a sample homepage built with it.

- `SKILL.md`, `readme.md` — design system guidance (Claude Design format)
- `tokens/` — CSS design tokens (colors, typography, layout, fonts)
- `components/` — React components with `.d.ts` types and per-component prompts
- `guidelines/` — token/scale reference cards
- `ui_kits/` — marketing site and console kit compositions
- `assets/`, `uploads/` — logo files
- `examples/M2M-Tech-Homepage.html` — exported homepage prototype
